### 2.2 核心原则

**原则 1：原位操作优先**
使用 `editor_sdk` MCP 对打开的文档进行原地查找替换，而非"提取文本→重写新文档"路线。`editor_sdk` 直接操作 OOXML 内部的 `w:t` 文本节点，格式属性（标题样式、表格属性、页眉页脚）完全不受影响。

> ⚠️ **已知限制**：editor_sdk 的 `doc_find_and_replace` 在大文档（10MB+）场景下存在状态同步问题，替换操作可能不落盘（返回 OK 但文档未实际修改）。**兜底方案**：当 editor_sdk 方案效果不稳定时，使用 `python-docx` 直接读取和保存文件，功能绕过 SDK 直接操作 OOXML，格式完全保留。实证 v5 最终版即用此方案完成脱敏。

**原则 2：内容层全覆盖**
文档内容分散在四个独立位置，缺一不可：
- 段落文本（`block['type'] == 'paragraph'`，`block['text']`）
- 表格单元格（`block['type'] == 'table'`，遍历 `block['cells']`）
- 页眉/页脚（含 logo 图片，图片内可能含银行名文字）
- 正文图片（截图画面内含敏感信息，需 OCR）

**原则 3：智能推断 + 精确验证并行**
不依赖完整预设名单，通过"角色词上下文"自动发现姓名：
```
系统负责人：[张三]           ← 角色词 + 冒号 + 姓名
业务负责人：[李四]
联系人：     [王五]
总行支持人员：[赵六]
技术经理：   [钱七]
```

## 三、关键技术实现

### 3.1 Word 6.0 OLE 文件解析

原始 `.doc` 文件为 Word 6.0 二进制格式（Composite Document File V2），需要用 `olefile` 解析：

```python
import olefile

def extract_doc_text(doc_path: str) -> str:
    """
    从 Word 6.0 OLE2 .doc 文件中提取文本。
    关键偏移：
      - 0x04 (2 bytes): cbMac，文本有效字节数（UTF-16 LE）
      - 0x800: 文本起始偏移
    """
    ole = olefile.OleFileIO(doc_path)
    wd = ole.openstream('WordDocument').read()

    # FIB 偏移 0x04: cbMac（文本有效字节数，16-bit LE）
    cbMac = int.from_bytes(wd[0x04:0x06], 'little')

    # 文本从偏移 0x800 起，UTF-16 LE 编码
    raw_text = wd[0x800: 0x800 + cbMac * 2]
    return raw_text.decode('utf-16-le', errors='ignore')
```

> **注意**：直接提取 `.doc` 文本会附带 HYPERLINK/PAGEREF/TOC/TIME 等 Word 内部字段代码，需要用 `_clean_word_fields()` 清洗后再处理。

### 3.2 日期正则模式（已验证修复版）

```python
import re

# 修复后的关键正则（全部经过真实数据验证）

_YEAR4 = r'[〇二三四五六七八九0-9]{4}'
# 原因：旧版 `[〇0-9]{4}` 缺少 二/三/四/五/六/七/八/九

_MONTH_PAT = (
    r'(?:'
    r'0?[1-9]|1[0-2]|'                    # 数字月份（支持'4月'和'04月'）
    r'[一二三四五六七八九](?=月)|'            # 一月~九月（lookahead防双消费）
    r'十(?=月)|'                             # 十月（lookahead）
    r'十一(?=月)|十二(?=月)|'              # 十一月、十二月
    r'正(?=月)'                             # 正月
    r')'
)
# 原因：旧版 `[一二三四五六七八九十]十?` 对'十月'：
#   '十' 被字符类消费，'十?' 再次尝试匹配'十'，导致'月'无字符可匹配 → 失败

_DAY_PAT = r'[^月]+(?=日)'
# 原因：旧版用 `十?` 尾缀导致'十七日'匹配失败。
# 新版：`[^月]+` 贪婪匹配所有非'月'字符，遇到'日'时 '日' 由尾部 literal 消费。

DATE_PATTERNS = [
    # 完整年月日（优先匹配）
    (re.compile(fr'{_YEAR4}年{_MONTH_PAT}{_DAY_PAT}日'), 'YYYY/MM/DD'),
    # 独立年月（负向前瞻确保月字后不跟数字/空格，即无日的情况）
    (re.compile(fr'{_YEAR4}年{_MONTH_PAT}(?![\s\d])'), 'YYYY/MM'),
]
```

### 3.4 银行名全量覆盖规则

```python
# 银行名替换规则（按优先级从高到低，避免短名先匹配覆盖长名）
BANK_NAME_RULES = [
    # 全称优先
    ('福建海峡银行股份有限公司', '福建XX银行股份有限公司'),
    ('福建海峡银行',             '福建XX银行'),
    # 简称（独立出现的"海峡银行"单独处理）
    ('海峡银行',                 'XX银行'),
]

def redact_bank_names(text: str) -> tuple[str, list]:
    """
    分两步走，确保无遗漏：
    1. 先替换全称（避免'海峡银行'先被替换导致'福建海峡银行'不完整）
    2. 再替换简称
    """
    records = []
    for old, new in sorted(BANK_NAME_RULES, key=lambda x: -len(x[0])):
        count = text.count(old)
        if count > 0:
            text = text.replace(old, new)
            records.append({'old': old, 'new': new, 'count': count})
    return text, records
```

### 3.5 段落 + 表格并行内容提取（已修复版）

```python
def extract_all_text(doc_content: dict) -> dict:
    """
    同时提取段落和表格单元格，避免遗漏表格中的敏感信息。

    editor_sdk 返回的 block 结构（.doc/.docx 通用）：

      段落 block:
        - type == "paragraph"
        - 优先读 block["text"]（完整文本）
        - 若 text 为空（.doc 某些块），从 block["content"][i]["t"] 拼

      表格 block（两种格式均支持）:
        - type == "table": 单元格在 block["table"]["cells"]
        - type == "text" 且 id 以 "tbl:" 开头: 同上
        - type == "text" 且含 "table" key: 同上

    ⚠️ 根因：旧版只读 block["text"]，但 .doc 文件表格在 editor SDK
      返回中用 type=="text" + id=="tbl:xxx"，而非 type=="table"。
      导致表格内容完全漏读 → LLM 看不到姓名 → 漏脱敏。
    """
    paragraphs = []
    table_cells = []

    for block in doc_content.get("content", {}).get("blocks", []):
        btype = block.get("type", "")

        if btype == "paragraph":
            text = block.get("text", "").strip()
            if not text:
                # .doc 嵌套 content：block["content"][i]["t"]
                parts = []
                for item in block.get("content", []):
                    t = item.get("t", "")
                    if t:
                        parts.append(t)
                text = "".join(parts).strip()
            if text:
                paragraphs.append(text)

        elif btype == "table":
            for cell in block.get("table", {}).get("cells", []):
                t = cell.get("text", "").strip()
                if t:
                    table_cells.append(t)

        # .doc 格式的表格 block：type=="text" 且 id 含 "tbl:"
        elif btype == "text" and block.get("id", "").startswith("tbl:"):
            for cell in block.get("table", {}).get("cells", []):
                t = cell.get("text", "").strip()
                if t:
                    table_cells.append(t)

        # .doc 含表格行的 text block（备用）
        elif btype == "text" and "table" in block:
            for cell in block.get("table", {}).get("cells", []):
                t = cell.get("text", "").strip()
                if t:
                    table_cells.append(t)

    return {
        "paragraphs": paragraphs,
        "table_cells": table_cells,
        "full_text": "\n".join(paragraphs + table_cells),
        "stats": {
            "paragraphs": len(paragraphs),
            "table_cells": len(table_cells),
            "total_chars": len("\n".join(paragraphs + table_cells)),
        }
    }
```

### 3.6 Word 内部字段代码清洗

```python
WORD_FIELDS = [
    # 目录字段
    (re.compile(r'TOC[^\n]{0,200}'), ''),
    # 超链接字段
    (re.compile(r'HYPERLINK\b[^\n]{0,200}?(?:\n|$)'), ''),
    # 页码引用字段
    (re.compile(r'PAGEREF\s+\S+[^\n]{0,100}?(?:\n|$)'), ''),
    # 时间字段
    (re.compile(r'TIME\s+\\@?"[^"]*"'), ''),
    # 引用字段
    (re.compile(r'REF\s+\S+[^\n]{0,80}?(?:\n|$)'), ''),
    # 样式引用字段
    (re.compile(r'STYLEREF\s+"[^"]*"[^\n]{0,60}?(?:\n|$)'), ''),
    # 零宽字符
    (re.compile(r'[\u200e\u200f\u200b\u200c\u200d\u202a-\u202e\ufeff\u00ad]'), ''),
    # 残留书签
    (re.compile(r'\b_Toc\d+\b'), ''),
    (re.compile(r'\b_Ref\d+\b'), ''),
    # 多余空格
    (re.compile(r'[ \t]{2,}'), ' '),
    # 多余换行
    (re.compile(r'\n{3,}'), '\n\n'),
]

def _clean_word_fields(text: str) -> str:
    for pattern, replacement in WORD_FIELDS:
        text = pattern.sub(replacement, text)
    return text
```

## 四、完整脱敏流程

```python
def redact_document(input_path: str, output_path: str, config: dict):
    """
    完整脱敏流程：
    1. 用 editor_sdk 原位打开（保留格式）
    2. 提取段落+表格全文（并行，避免遗漏）
    3. 并行扫描四类敏感信息（银行名/日期/姓名/图片）
    4. 合并去重后批量替换（从后往前，防止索引偏移）
    5. 保存为新文件 + 生成脱敏报告
    """
    # Step 1: 打开
    file_id = editor_sdk.open_file(input_path)
    content = editor_sdk.doc_get_document_content(file_id)

    # Step 2: 全量提取（段落+表格，缺一不可）
    all_text = extract_all_text(content)

    # Step 3: 扫描敏感信息
    bank_names = scan_bank_names(all_text['full_text'])
    dates = scan_dates(all_text['full_text'])

    # 姓名分两路：已知库精确匹配 + 智能推断
    known = scan_known_names(all_text, config['known_names'])
    inferred = extract_names_from_context(all_text['full_text'])
    all_names = (known | inferred) - config['excluded_names']

    # Step 4: 合并去重（防止段落和表格重复替换导致索引偏移）
    replacements = deduplicate_replacements(bank_names, dates, all_names)

    # Step 5: 分批替换（从后往前，避免索引偏移）
    for old_text, new_text in reversed(sorted(replacements, key=lambda x: -len(x[0]))):
        editor_sdk.doc_find_and_replace(file_id, old_text, new_text)

    # Step 6: 图片处理（OCR + 马赛克）
    image_results = process_images_for_sensitive_content(input_path)

    # Step 7: 保存
    editor_sdk.save_file(file_id, output_path)

    # Step 8: 生成脱敏报告
    report = build_report(replacements, image_results)
    return report
```

### 6.1 editor_sdk 写入不落盘问题（已绕过）

**现象**：`editor_sdk.doc_find_and_replace` 返回 `[OK]` / `{"status":"ok"}`，但 python-docx 重新读取发现替换未生效。

**根因**：editor_sdk 内部有缓存/状态管理，修改未真正写入磁盘。

**绕过方案**：对关键脱敏步骤改用 `python-docx` 直接读写 `.doc` 文件：

```python
from docx import Document
from pathlib import Path

def direct_redact(input_path: str, output_path: str,
                  names: list[str], branches: dict[str, str]):
    """
    python-docx 兜底方案：直接读取+修改+保存，彻底绕过 editor_sdk 写入问题。
    适用场景：editor_sdk doc_find_and_replace 后替换未生效时。
    """
    doc = Document(input_path)

    # 替换所有段落 runs
    for p in doc.paragraphs:
        for run in p.runs:
            if run.text:
                run.text = _apply_all(run.text, names, branches)

    # 替换所有表格单元格 runs
    for t in doc.tables:
        for row in t.rows:
            for cell in row.cells:
                for p in cell.paragraphs:
                    for run in p.runs:
                        if run.text:
                            run.text = _apply_all(run.text, names, branches)

    doc.save(output_path)

def _apply_all(text, names, branches):
    result = text
    for name in names:
        result = result.replace(name, "XXX")
    for old, new in sorted(branches.items(), key=lambda x: -len(x[0])):
        result = result.replace(old, new)
    return result
```

**经验教训**：
- editor_sdk 的 `doc_find_and_replace` 适合小文档；大文档（10MB+）可能有状态同步问题
- `python-docx` 直接修改 OOXML 内部的 `w:t` 节点，格式完全保留，效果更可靠
- 建议 future pipeline 中将 `execute_manifest` 的兜底切换为 python-docx
