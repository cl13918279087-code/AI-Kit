## 本次会话解决的问题

### D5 城市列举句脱敏 — 三个深层 bug 全部修复

**Bug 1: UnboundLocalError — `_CITY_ENUM_RE` 使用在定义之前**
- **根因**：`patterns.append((_CITY_ENUM_RE, ...))` 在第1305行（当时），但 `_CITY_ENUM_RE = re.compile(...)` 在第1328行。Python 将同函数内的变量视为局部变量，导致 `UnboundLocalError`，整个 `apply_redactions_counted` 崩溃。
- **修复**：将 D5 整个代码块（D5 `_CITY_ENUM_CITIES` → `_CITY_ENUM_RE` → `_city_enum_repl` → `patterns.append`）整体移到 `_CITY_BANK_RE` 定义之前。

**Bug 2: 变量顺序矛盾 — `_CITY_BANK_RE` 先 append 导致 `_CITY_ENUM_RE` 永远不执行**
- **根因**：代码注释说"必须在 _CITY_BANK_RE 之前 append"，但实际代码先 `patterns.append(_CITY_BANK_RE)`，后 `patterns.append(_CITY_ENUM_RE)`。且 `_city_bank_repl` 的 fallback 会吞掉"玉溪"，导致 D5 永远匹配不到。
- **修复**：调整执行顺序为 D5 先，`_CITY_BANK_RE` 后。

**Bug 3: Regex 结构双重错误**

① **第一分支：`(?:`及`)?` 无法匹配"及昆明、昭通..."**
- **根因**：`(?:`及`)?(?:城市(?:、|和|与))*` 中，"及"后必须有城市，但文本是"及昆明、昭通..."，中间有顿号分隔符。
- **修复**：`(?:`及`)?` → `(?:(?:、|和|与)?及)?`

② **第二分支：province 必填导致独立城市名无法匹配**
- **根因**：`_CITY_ENUM_CITIES` 是 `"云南(?:昆明|玉溪|...)"` 形式，要求 province 前缀。测试文本"玉溪保证金系统"中没有"云南"，regex 永远匹配不到。
- **修复**：每个分支改为 `"(?:云南)?(?:昆明|玉溪|...)"`，province 可选。

③ **`_city_enum_repl` 逻辑**：`has_enum` 检查完整列举（顿号分隔城市），单城市直接返回"XX"。
