本行人工确认真名补充清单（extra_name_list）说明
==================================================

用途
----
本文件是「常规闸门无法识别、但已人工确认是人名」的补充清单。

典型场景：某些姓名的**名字位用字在语料中频次为 0**（生僻字），
常规的字频闸门救不回它们，导致这类姓名系统性漏脱。
本清单中的条目按**精确匹配**脱敏，不受字频闸门限制。

格式
----
- 每行一个姓名，UTF-8 编码
- 以 # 开头的行视为注释，忽略
- 空行忽略
- 重复条目自动去重

生效方式（优先级由高到低）
--------------------------
1. 环境变量 AIKIT_EXTRA_NAME_LIST 指向外部文件
2. config.json 的 extra_name_list_file 配置项
3. 本文件（包内默认路径 scripts/data/extra_name_list.txt）

留空的影响
----------
留空**不会**导致程序报错，但会使「生僻字姓名兜底通道」失效：
该类姓名仍会漏脱。若本行文档中可能出现这类姓名，请务必填写。

与花名册的分工
--------------
- scripts/data/full_name_list.txt ：本行员工花名册（全员，常规路径）
- scripts/data/extra_name_list.txt ：人工确认真名补充（生僻字等特殊情况）

两者都会并入 D16 精确匹配层；本清单额外获得「不设字频门槛」的待遇。

安全提示
--------
本文件属于个人敏感信息，请按内部数据管理规范保存，
不要提交到公开代码仓库或随包外发。
