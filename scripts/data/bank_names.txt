# 目标银行名称清单（每行一个，UTF-8）
#
# 用途：这些是**需要被脱敏遮盖**的目标机构名。
# 技能包会据此派生机构名正则（含各分支行/支行/营业部变体），
# 命中的机构名会被替换为「XX银行」等占位符。
#
# 请填入：
#   · 本行及本集团各法人机构的名称
#   · 文档中可能出现、且需要脱敏的目标机构（客户/合作方/第三方等）
#
# 格式示例：
#   XX银行
#   XX银行股份有限公司
#
# 生效方式（二选一）：
#   1) 本文件已由 config.json 的 bank_names_file 指向，直接填写即可；
#   2) 设环境变量 AIKIT_BANK_NAMES=/绝对路径/本文件（优先级更高）。
#
# 说明：机构名兜底规则「2-6 个汉字 + 银行」始终生效，
#       即便本文件为空，常见的「XX银行」形态仍会被脱敏；
#       本文件用于补充带地区前缀/长后缀的变体（如「XX银行福州分行」）。
